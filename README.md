# sandhoff.digital

Website von sandhoff.digital.

## Lokale Entwicklung

```sh
git clone <this-repository-url>
cd <repository-name>
npm i
npm run dev
```

## Fertigen FTP-Upload erzeugen

```sh
npm run build
```

Der vollständig statische Webauftritt liegt danach direkt im Ordner `dist`.
Weitere Hinweise stehen in `DEPLOY.md`.
